Color Exchange - OFX plugin for VEGAS Pro (Windows x64)

Copy the whole "ColorExchange.ofx.bundle" folder to:
  C:\Program Files\Common Files\OFX\Plugins\
Restart VEGAS Pro, then find it under Video FX > OFX > Color > Color Exchange.
(Prebuilt, no installer and no runtime needed.)

Color 1 = colour in the video to change.  Color 2 = colour to change it into.
EYEDROPPER: move "Eyedropper Point" onto the colour you want (0,0 = bottom-left,
1,1 = top-right), then click "Pick Color 1 (Eyedropper)". Color 1 becomes that colour.
Tolerance / Softness control how wide a range of Color 1 gets swapped.
